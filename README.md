# 1337 GitHub Banner

A beautiful Next.js web application showcasing a banner for 1337 school students on GitHub.

![1337 GitHub Banner](https://github.com/user-attachments/assets/ffe33d5f-194f-416b-b2cf-3afa7eae3c13)

## Tech Stack

- **Next.js 14.2** - React framework with App Router
- **TypeScript** - Type-safe JavaScript
- **React 18** - Latest React features
- **CSS3** - Modern styling with gradients and responsive design

## Features

- 🎨 Beautiful gradient design
- 📱 Fully responsive layout
- ⚡ Fast static site generation
- 🔒 Secure and up-to-date dependencies
- 🎯 TypeScript for type safety
- ✨ Modern UI with smooth animations

## Getting Started

### Prerequisites

- Node.js 18+ installed
- npm or yarn package manager

### Installation

1. Clone the repository:
```bash
git clone https://github.com/AKL001/1337-GitHub-Banner.git
cd 1337-GitHub-Banner
```

2. Install dependencies:
```bash
npm install
```

3. Run the development server:
```bash
npm run dev
```

4. Open [http://localhost:3000](http://localhost:3000) in your browser to see the result.

## Available Scripts

- `npm run dev` - Start development server
- `npm run build` - Build for production
- `npm start` - Start production server
- `npm run lint` - Run ESLint
